# Archivist guide
Digital archive → New volume. Enter collection, volume title, date range, language, physical condition and custodian. Do not infer missing history. Upload a PDF/JPEG/PNG up to 25 MB and a page/folio label. The system preserves original bytes and stores the checksum, size and uploader. Originals can have separate metadata references even when their checksums match.

Open a source for zoom/rotate/fit. These controls affect only the view. Downloads are restricted and audited. Do not place original storage in a public web directory. Whole PDFs can be manually transcribed. Local OCR in the Docker worker creates separate PDF working pages and draft review jobs. Original PDFs remain unchanged. Text regions and provider confidence are review aids; handwriting recognition has not been evaluated and all uncertain fields need human transcription.

Run regular original-file checksum checks and restore exercises with the operator. Preserve source volumes and physical registers according to church policy. Never delete an official source simply because transcription is complete.
