## Decisions
Pilot tradition confirmed by user: **Roman Catholic**. English is a reversible initial UI assumption; Unicode personal data is accepted. Cloud OCR remains off; no external document provider is called. Manual transcription is first-class. Maker/checker is enabled by default. Official certificate text is not invented. Subscription payment collection is deferred as permitted by §20.

## Release acceptance
MVP complete (§28) and production rollout are **not yet claimed**. The table is deliberately explicit: implemented core workflows do not imply completion of every P0 subrequirement. In particular, approved HTR samples/provider evaluation, richer archival workflows and production operational qualification remain. Expansion should follow the milestone plan and preserve existing isolation tests.
