# Record clerk guide
Search Members first, including alternate spellings, before creating a person. Add only necessary personal information. Household selection connects the current family. Date precision may be unknown, approximate, year or exact; do not invent missing days or months.

Member photos are optional. Choose or drop a JPEG, PNG or WebP image on the profile photo area, then Save member. Photos must be at most 5 MB and 16 megapixels; they are resized, stripped of metadata, and kept private. Remove photo and save to delete the active image. Use Find a household when the household is outside the first set of dropdown results.

Households lets you assign families to admin-created parish units, search/filter by unit or review state, and see counts across all matching pages. New households start in draft. Save changes before submitting; a unit must be assigned. A different authorised reviewer approves or rejects them. Editing an approved household returns it to draft. Existing households were migrated as drafts because the old directory had no approval evidence.

For each register, choose its type and event year. Tables group records by calendar year, and counters show every matching status independently of pagination/status filtering. Approximate and unknown dates remain in Unknown / uncertain year. First Holy Communion and standalone Burial are available alongside the existing registers; historical combined Death & burial forms remain intact.

Registers → New record → choose a versioned register and person (use Find a member for larger directories). Enter the event-time name if different from the current member name, event/source details and save a draft. The recorded name stays independent of later profile changes. Review/edit and submit. An authorised independent reviewer approves or returns it with a reason. Approved records are protected; request a documented amendment rather than editing them.

Member profiles include dated family connections, household assignment history and documented membership events. Administrators can link manually verified duplicate profiles and reverse that link; historical sacramental references remain attached to their original identities. Similarity suggestions never merge people automatically.

Digitisation → New transcription → choose a preserved original and schema. Manual mode always works. Compare fields and raw text with the original; zoom/rotate the viewer as needed. Leave illegible content blank. Complete human review. An authorised importer creates a draft, which still requires submission and official approval. Repeating import will not duplicate the entry.
