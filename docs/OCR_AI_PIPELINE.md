# OCR and human review
Adapters: `manual` and self-hosted `tesseract`. Manual transcription works without Redis and creates no synthetic extraction. Tesseract is a printed-text baseline, not a handwriting accuracy claim. Redis/BullMQ carries only persisted job/tenant IDs. Worker reloads the job through RLS before accessing originals. Concurrency is 1; automatic attempts 3 with exponential backoff, and failed jobs can be retried manually.

Worker preserves raw text, aggregate confidence, provider version and word regions in append-only `ocr_results`. Coordinates are normalised [x0,y0,x1,y1] in [0,1] relative to the source image or derived PDF working page. They rotate/zoom with the image. Human-edited text and structured values stay separate. Schema mapping is manual; no invented field values. Complete review → import draft, keyed by unique job; official approval still requires a distinct workflow. Duplicate requests return the same imported entry ID. The human preparer is recorded as the maker, while import and approval actors are separately audited.

No document is sent to a cloud provider. ai_enabled only enables local OCR. First Tesseract invocation downloads English trained data into `data/ocr-cache`; provision it for offline use. PDF originals can also be transcribed manually. Local Poppler rasterises 1–200 pages at a maximum 2,200-pixel side, with a 100 MB aggregate working-image limit. It runs with argument arrays, a time limit and private temporary files. Fonts are included in Docker; Windows-local workers need Poppler/fonts installed separately. Each page has a separate job and immutable derived image, linked to the unchanged PDF. Multi-row segmentation/automatic field mapping are not implemented.

Every minute the worker reconciles persisted queued jobs missing from Redis and marks processing jobs stale after 15 minutes as failed for explicit retry/manual recovery. Monitor dead jobs and attempts; test outage scenarios under production load. The queue stores IDs only. Source PDF checksums and zero automatic official entries are verified by `tools/check-pdf.ts` using synthetic two-page documents.
